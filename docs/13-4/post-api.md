| ID     | メソッド | エンドポイント  | 何をするか                         | 認証 |
| :----- | :------- | :-------------- | :--------------------------------- | :--- |
| API-01 | GET      | /api/posts      | 登録されている投稿を一覧で表示する | 必須 |
| API-02 | GET      | /api/posts/{id} | 投稿を1件表示する                  | 必須 |
| API-03 | PUT      | /api/posts/{id} | 選択した投稿を編集する             | 必須 |
| API-04 | DELETE   | /api/posts/{id} | 選択した投稿を削除する             | 必須 |
