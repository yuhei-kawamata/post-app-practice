#### カフェモバイルオーダーアプリ API設計書

| ID     | メソッド | エンドポイント         | 何をするか                                           | 認証 |
| :----- | :------- | :--------------------- | :--------------------------------------------------- | :--- |
| API-01 | GET      | /api/menus             | その日の商品を一覧で表示する                         | 不要 |
| API-02 | POST     | /api/orders            | 買い物かごに入れた商品を注文する                     | 不要 |
| API-03 | GET      | /api/orders/{注文番号} | 注文1件の状況を確認する                              | 不要 |
| API-04 | DELETE   | /api/orders/{注文番号} | 注文を取り消す                                       | 不要 |
| API-05 | GET      | /api/orders/           | 受け取り前の注文を、商品と個数とともに一覧で表示する | 必須 |
| API-06 | PUT      | /api/orders/{注文番号} | 注文を受け取り済みに変更する                         | 必須 |

#### API-02: 買い物かごに入れた商品を注文する

- **メソッドとエンドポイント**: POST /api/orders/
- **認証**: 不要
- **送るもの**:本文で、商品（空にできない、文字列、255文字以内）、個数（空にできない、1~10までの整数）を送る
- **返すもの（うまくいったとき）**: 201。注文番号、合計金額、支払い手続きに進めるためのリンク
- **返すもの（うまくいかなかったとき）**: 422（送ったものに不備があるとき、選んだ商品が売り切れのとき）

#### API-06: 注文を受け渡し済みにする

- **メソッドとエンドポイント**: PUT /api/orders/{注文番号}
- **認証**: 必要
- **送るもの**: URLに注文番号。本文で、受け渡し済みにすること
- **返すもの（うまくいったとき）**: 200。書き換えたあとの注文1件（注文番号・商品と個数・合計金額・受け渡し済みであること）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）／404（その注文番号の注文が無いとき）

#### エラーレスポンス

| 起きること                                                         | ステータスコード | 返すもの                                 |
| :----------------------------------------------------------------- | :--------------- | :--------------------------------------- |
| 注文内容に不備がある                                               | 422              | 不備のあった項目とその理由               |
| 売り切れの商品が注文された                                         | 422              | 「この商品は売り切れです」               |
| 指定した注文番号の注文が見つからない（お客様の状況確認・取り消し） | 404              | 「指定の注文番号の注文は見つかりません」 |
| 指定した注文番号の注文が見つからない（店員の受け渡し）             | 404              | 「指定の注文番号の注文は見つかりません」 |
| ログインしていない（店員）                                         | 401              | 「ログインしてください」                 |
