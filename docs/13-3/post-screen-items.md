| 項目名                     | 種類           | 必須 | 内容                                                                                    |
| :------------------------- | :------------- | :--- | :-------------------------------------------------------------------------------------- |
| 画面見出し                 | 表示           | -    | 「投稿編集」                                                                            |
| タイトル                   | 入力（1行）    | 必須 | 投稿のタイトル。開いた時は現在の値が入っている                                          |
| カテゴリ                   | 選択           | 必須 | 事前に登録されているカテゴリから1つ選択する。開いたときは現在のカテゴリが選択されている |
| 本文                       | 入力（複数行） | 必須 | 投稿の本文。開いたときは現在の値が入っている                                            |
| 投稿を更新するボタン       | ボタン         | -    | 押すと記入した内容で投稿が更新され、投稿一覧画面に移る                                  |
| 編集をキャンセルするボタン | リンク         | -    | 押すと記入した内容で投稿を更新せず、投稿一覧画面に移る                                  |
