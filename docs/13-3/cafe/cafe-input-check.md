| 画面         | 項目       | 必須 | 文字数・桁数    | 形式・値の範囲                             | ほかの項目との関係 |
| :----------- | ---------- | ---- | --------------- | ------------------------------------------ | ------------------ |
| 商品一覧画面 | 個数       | 必須 | 1～10までの整数 | 数値（プルダウンで選択）                   | -                  |
| 支払い画面   | 支払い方法 | 必須 | -               | あらかじめ用意された支払い方法の中から選択 |                    |

変更となる可能性がある。
