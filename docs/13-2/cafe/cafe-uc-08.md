#### UC-08: 作成完了にステータスを変更する

- **アクター**: 店員

- **事前条件**: 注文が1件以上入っていて、注文一覧画面に表示されている

- **基本フロー**:
    1. 注文一覧画面の内容に基づき、店員が商品を作成する
    2. 作成した商品を、店員がお客さんに渡す
    3. お客さんに商品を渡したら、店員が該当する商品の「完了」ボタンを押す
    4. 「完了」となった注文は、注文一覧画面から表示が消える

- **代替フロー**:
    - なし

- **事後条件**: 注文一覧画面から、「完了」した商品の表示がなくなる

- **受け入れ条件**:
    - [ ] 注文が1つ以上一覧画面に表示されている場合に、「完了」ボタンが表示される
    - [ ] 「完了」ボタンを押すと、注文一覧画面から表示がなくなる
