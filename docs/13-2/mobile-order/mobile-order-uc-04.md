#### UC-04: 支払う

- **アクター**: お客さん

- **事前条件**: 注文したい商品を、1つ以上事前に選択している。

- **基本フロー**:
    1. お客さんが「注文」ボタンを押す
    2. システムが支払い方法選択画面を表示する
    3. お客さんが支払い方法を選択する
    4. お客さんが選択した支払い方法に基づき支払い手続きを実施する
    5. システムが支払処理を行い、完了したらメッセージを表示する

- **代替フロー**:
    - 1a. 注文したい商品が1つも選択されていない場合、1つ以上商品を選択するよう、システムがエラーメッセージを表示する
    - 4a. お客さんが実施した支払い手続きに誤りがある場合、システムがエラーメッセージを表示して、3.の手順に戻る

- **事後条件**: 注文一覧画面に、注文内容が反映される

- **受け入れ条件**:
    - [ ] 注文したい商品が1つ以上選択されている場合に、「支払う」ボタンが表示される
    - [ ] 事前に登録した支払い方法が選択できる
    - [ ] 支払い手続きに誤りがある場合、エラーメッセージが表示され、注文が成立していない
