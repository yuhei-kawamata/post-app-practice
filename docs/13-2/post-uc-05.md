#### UC-05: 投稿を編集する

- **アクター**: ログイン済みの利用者

- **事前条件**: 利用者としてログインしている。1つ以上事前にログイン済み利用者自身の投稿が登録されている。

- **基本フロー**:
    1. ログイン済みの利用者が一覧画面で投稿の「編集」ボタンを押す
    2. システムが投稿の編集画面に、今のタイトル・カテゴリ・本文を表示する
    3. ログイン済みの利用者が編集内容を入力して、「更新」ボタンを押す
    4. システムが投稿を更新する

- **代替フロー**:
    - 1a. 他人の投稿の編集画面のURLを直接開いた場合：システムは403エラーメッセージを表示する
    - 3a. 編集内容に誤りがある場合：システムはエラーメッセージを表示して、投稿を更新しない

- **事後条件**: 一覧画面に、編集内容が反映された投稿が表示される

- **受け入れ条件**:
    - [ ] 投稿一覧画面で、自分の投稿にだけ「編集」ボタンが表示される
    - [ ] 内容を変更して「更新」ボタンを押すと、投稿一覧画面に変更内容が反映される
    - [ ] タイトルを空にして「更新」ボタンを押すと、エラーメッセージが表示され、投稿の内容は変更されない
